# Security Policy

## Supported Versions
Project Obsidian actively supports the following platforms:

| OS Version | Architecture | Supported |
| :--- | :--- | :--- |
| Windows 11 25H2 | x64 | :white_check_mark: |
| Windows 11 24H2 | x64 | :white_check_mark: |
| Windows 11 23H2 | x64 | :white_check_mark: |
| Windows 10 (Legacy) | x64 | :x: (Unsupported) |

## Reporting a Security Concern
If you discover an issue where a modification:
1. Unintentionally weakens Windows Defender, SmartScreen, or BitLocker;
2. Breaches system stability or causes an operating system failure;
3. Interferes with anticheat drivers (EAC, BattlEye, Vanguard);

Please open a private advisory on GitHub or email `security@project-obsidian.dev`. We respond within 48 hours and coordinate a patch through our CI/CD pipeline.
